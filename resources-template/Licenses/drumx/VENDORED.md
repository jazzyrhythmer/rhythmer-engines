# DRUM-X

Original JIANT fixed-point DRUM-X voice, helpers, generator and nine factory kits. The original files and hashes are preserved. Generated C++ scoping changes globals to per-instance fields; DSP expressions and 32-sample control rate remain unchanged. The native adapter supplies MIDI, velocity, linear pan, bounded 32-frame buffering and project state. Each of the eight lanes is monophonic, as in the original. Full firmware, global FX, sequencer and ROM are not embedded.
