# Source and license inventory

See THIRD_PARTY_NOTICES.md for component attribution, SOURCE_LOCK.json for source pins, config/releases.lock.json for prebuilt provenance, and ports/*/VENDORED.md for local changes.

The runtime uses AGPL-3.0-only components. JIANT/Rhythmer musical adaptations use GPL-3.0-only source with preserved notices. Open MPC wrapper and Sophie notices, TR-MPC source/asset notices, JUCE dependencies and Rubik font licensing are retained with their components.

A repository's root license does not automatically cover every nested dependency, sound bank or sample. Additional engines/assets require file-level review before inclusion. Local development artifacts are not a declaration of final public release clearance.
