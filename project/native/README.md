# Native MPC 3 instrument

Rhythmer Engines by Jazzy Rhythmer, UID `JFq7`, private hardware-test version 0.1.0.

The instrument and 26 unique bundled source cores have ARM32 and ARM64 builds.
There are 22 engine entries, 36 complete kits and 2,888 source sound selections.
All 4,228 source control definitions remain available to the native editor;
read-only/inactive source controls are retained in the inventory.

See [installation, pages, GEN and limits](Rhythmer%20Engines/README.md).
The browser preview is separate and does not play audio. Native software
checks are recorded in `validation.json`; physical MPC testing is separate.
No public release was made. Install only through the MPC's `VST2 Plugins`
folder on MPC OS 3.10.1+ with external plug-in support enabled.
